Cómo publicar tus cambios en el sitio real

Los cambios que haces aquí se guardan automáticamente en este navegador para que puedas previsualizarlos en Ver sitio y Ver tienda. Para que todos los visitantes vean los cambios, sigue estos pasos:

  1. Haz clic en Descargar products.json.
  2. Reemplaza el archivo products.json en tu repositorio de GitHub por el que acabas de descargar.
  3. Haz commit y push — Render volverá a publicar el sitio automáticamente.

Si en otro momento quieres seguir editando desde cero, usa Importar products.json para cargar el archivo publicado actual en este panel.
